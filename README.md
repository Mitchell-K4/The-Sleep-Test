# The Sleep Test
The Sleep Test is an Android educational mobile quiz application developed using Unity and C# that provides an interactive study and testing experience through multiple-choice questions, scoring, and immediate user feedback. Upon successfully passing the quiz, users receive a personalized certificate that is automatically saved to their device's local image gallery.

## Features
- Automatic score calculation
- Instant feedback for submitted answers
- Pass/fail evaluation
- Personalized certificate generation
- Certificate saved to the device's image gallery
- Randomized question order
- Randomized answer order
- Progress tracking during the quiz
